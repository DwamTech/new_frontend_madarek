# طلبات تعديل معلّقة على الباكند

هذا المجلد يجمع كل طلبات إضافة/تعديل الحقول في `back.mdarek.net` التي حدّدها فريق الواجهة الأمامية أثناء بناء النسخة الجديدة، ولم تُنفَّذ بعد. كل طلب في ملف مستقل بنفس الصيغة: السياق، التعديل المطلوب، لماذا لا تكفي الحقول الموجودة، وأثر التعديل على الموقع الحالي.

| الطلب | الحالة | الملف |

| الملفات الخاصة (Dossiers) | معلّق | [01-dossiers.md](./01-dossiers.md) |
| شجرة المواضيع (Topics) | معلّق | [02-topics.md](./02-topics.md) |
| التعليقات وتفاعل الإعجاب/عدم الإعجاب | معلّق (القراءة جاهزة، الكتابة تحتاج قرارًا) | [03-comments-reactions.md](./03-comments-reactions.md) |
| تفعيل خدمة الاشتراك بالنشرة البريدية | يحتاج قرارًا | [04-newsletter-subscription.md](./04-newsletter-subscription.md) |

## ملاحظة لمبرمج الباكند

طبقة استهلاك الـ API الحالية في `src/lib/mdarek-api/raw-types.ts` توثّق **كل** حقل يُستهلك فعليًا من الـ API اليوم — أي إضافة حقل جديد لن تكسر شيئًا (الطبقة تتجاهل أي حقل غير معروف لها). لا حاجة لأي تغيير في الحقول الموجودة، هذه إضافات فقط.
